================================================================================
1. PROJECT OVERVIEW
================================================================================

ExamPilot AI is a universal AI-powered examination preparation and mock-test
platform. It works for ANY examination — UPSC, APSC, SSC, GATE, State PSCs,
Teaching exams, Law, Management, Engineering, Science, Commerce, and any custom
exam.

Core Vision:
  EXAM → OFFICIAL SYLLABUS → SUBJECTS/BRANCHES → DOMAINS → TOPICS →
  SUBTOPICS → KNOWLEDGE → THEORIES/LAWS/FORMULAS/FACTS → QUESTIONS →
  MOCK TESTS → PERFORMANCE → ADAPTIVE LEARNING

Positioning: AI-first differentiation (not catalog breadth).
  - Understands YOU: diagnostic + adaptive engine modeling per-subtopic mastery
  - Explains, doesn't just answer: syllabus-grounded tutor with citations
  - Gets out of the way: sub-second, offline-capable, keyboard/thumb-native

6.3 Research Engine (per PROMP.txt §8)

  - Anti-hallucination validation (6 statuses: verified, supported, inferred,
    unverified, conflicting, needs_review)

6.4 Question Engine (per PROMP.txt §16-24)
  - Deterministic numerical recipes (18+): answers computed in code
  - AI question generation with comprehensive validation
  - Distractor engine: plausible wrong options from error patterns
  - 7-dimension question validation: factual accuracy, answer correctness,
    unique answer, logical consistency, numerical validation, ambiguity check
  - Duplicate detection: exact, semantic, near-duplicate
  - PYQ storage with full metadata

6.5 Numerical Validation (per PROMP.txt §21)
  - Generate data → Solve independently → Recalculate → Check dimensions →
    Check units → Check assumptions → Check physical reasonableness →
    Generate realistic distractors → Store solution steps

7. MOCK TEST ENGINE
================================================================================

Per PROMP.txt §25-38:

Exam Blueprint: question count, duration, negative marking, difficulty
  distribution, subject distribution, topic distribution, question type
  distribution

Mock Test Types: Full Mock, Subject Test, Domain Test, Topic Test,
  Chapter Test, Previous Paper Simulation, Daily Test, Revision Test,
  Weak Area Test, Adaptive Test, Custom Test

Adaptive Mock Engine: considers mastery, recent accuracy, difficulty, topic,
  question type, response time, previous errors
  - Strong medium performance → hard question
  - Hard question incorrect → targeted medium question
  - Correct → related hard question

AI Remediation Flow: MOCK → WEAKNESS → THEORY → MEDIUM → HARD → RETEST → MASTERY

Study Plan: allocates learning/practice/revision/mock hours across available days

Timer: 02:00:00 countdown with 10min, 5min, 1min warnings; auto-submit at zero;
  autosave answers; browser refresh protection

11. AI MODEL ROUTING
================================================================================

Per PROMP.txt §48:
  - Fast/cheap model: classification, tagging, basic extraction
  - Strong reasoning model: hard question generation, numerical reasoning,
    validation, difficult explanations
  - Research model: web research, source synthesis
  - Embedding model: semantic search, duplicate detection, knowledge retrieval

Gemini Model Rotation (in geminiService.ts):
  gemini-3.8-flash → gemini-3.6 → gemini-2.5 (caches winner in localStorage)

RAG Pipeline (per PROMP.txt §49):
  USER QUESTION → QUERY UNDERSTANDING → RETRIEVE RELEVANT KNOWLEDGE →
  RETRIEVE SOURCES → LLM → ANSWER

14. GAMIFICATION SYSTEM
================================================================================

Achievement Badges (8):
  - First Question, Study Streak (3/7/30 days), High Scorer (80%),
    Mock Champion, Perfect Score, Dedicated Learner (100 questions)

XP System:
  - questionsSolved × 10 + studyStreak × 5 + accuracyRate × 2
  - Level = floor(xp/100) + 1
  - XP to next level = level² × 100

Features:
  - Animated XP bar with gradient fill
  - Streak counter with fire animation
  - Achievement badges with shine on unlock
  - Level-up celebration with confetti + "LEVEL UP!" animation
  - Subject mastery bars with animated width

17. ANTI-HALLUCINATION SYSTEM
================================================================================

Verification statuses:
  - VERIFIED — Confirmed from official sources
  - SUPPORTED — Backed by reference material
  - INFERRED — Logically derived but not explicitly stated
  - UNVERIFIED — Cannot confirm from sources
  - CONFLICTING — Sources disagree
  - NEEDS_REVIEW — Failed validation checks

Never fabricates: URLs, sources, citations, facts, statistics, formulas,
laws, exam rules, question answers
